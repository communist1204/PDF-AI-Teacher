PDF AI Teacher - local reference voice experiment

The user selected six public audio samples from Alibaba Cloud's official
CosyVoice voice-list page, which provides audio previews and right-click save:
https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list

The samples are downloaded separately for this user's local experiment.
They are NOT covered by the CosyVoice code's Apache license, and this project
does NOT assert a separate commercial voice, redistribution, or endorsement
license. No sample audio is included in Git or in the desktop package.

The local Fun-CosyVoice3-0.5B-2512 model uses these recordings as acoustic
references. Resulting voices are approximate local reference versions, NOT
Alibaba Cloud's native preset voices and NOT a promise of identical quality.
No cloud synthesis API is used. The user must evaluate the generated audio.

The originals are decoded to mono 24 kHz PCM WAV without hard cutting.
Source URLs and hashes, derived-file hashes, and the inference mode are in
cosy-voices.json. No unverified automatic transcription is used as a prompt.
