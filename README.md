# PDF AI Teacher

本机运行的中文 PDF 学习工作台，当前交付 M0/M1 基础版。支持真实 PDF.js 阅读与选区、公式区域预览、结构化教案黑板、文字问答、所选原文朗读和句级续读。语音提问与实时插话属于后续 M2/M3。

## 启动

需要 Node.js 22.13+（本机验证版本 24.19.0）。在本项目 PowerShell 终端执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

**先启动服务，再打开网页；使用期间请保持启动终端运行。** 关闭终端或重启电脑后，需要重新执行上面的启动命令。打开 http://127.0.0.1:4317 。用「示例」打开项目自制中文 PDF，或选择/拖入自己的文件。终端 Ctrl+C 停止本项目服务。Windows 执行策略限制 npm.ps1 时使用 npm.cmd，无需更改系统策略。

未创建 .env 时默认明确演示模式：本地 PDF、选区、板书可验证；示例教案不是模型回答。演示朗读使用浏览器提供的本机中文合成声音，缺少本机中文语音时会说明原因。它不代表 OpenAI TTS 或 Realtime 已接通。

## 本机配置 API

```powershell
Copy-Item .env.example .env
```

只在本机编辑 .env，填写自己的 OPENAI_API_KEY，以及账号实际可用的 CHAT_MODEL、VISION_MODEL、TTS_MODEL。设置 DEMO_MODE=false 并重启服务。不要把 Key 发到聊天、放进前端变量或提交 Git。

模型名不预填为“已验证”默认值；.env.example 提供字段说明；模型请依据官方模型目录与自己账号的权限选择。配置后状态仍为“待验”，不能据此认定账号具有权限。真实请求由你点击触发，可能产生独立于 ChatGPT 订阅的 API 费用；本轮未调用付费接口。首次只测试短选区、一张局部截图和一句朗读。

## 自然朗读

演示模式调用 Windows / 浏览器本机语音，语气能力有限。接入支持语气指导的 TTS 后，可配置自然、温和、按语义停顿的朗读；不能承诺与真人或 GPT-Live 一样。

在本机 .env 中设置自己的 Key，并可参考官方文档样例（须具备账号权限）：

```dotenv
DEMO_MODE=false
TTS_MODEL=gpt-4o-mini-tts
TTS_VOICE=marin
TTS_INSTRUCTIONS=语气自然温和，像面对面陪读，适当停顿，避免播音腔。
```

可尝试 cedar 音色。以上是官方支持的配置示例，**未做真实接口或中文听感验证**；官方说明声音目前侧重英语优化。后端始终附加忠实朗读原文的要求，不额外添加对白。修改后重启服务并刷新网页。

自定义语气只发给已确认支持 instructions 的模型。tts-1 / tts-1-hd 不支持；兼容服务要先查该服务文档，再显式配置 TTS_SUPPORTS_INSTRUCTIONS=true，不把文字兼容性当成语音兼容性。模型未支持时使用其默认语气，配置冲突会明确报错。

GPT-Live 连续语音对话、麦克风输入和实时插话尚未接入；现阶段自然 TTS 仅负责朗读。

## 使用

1. 选择 PDF 文字，检查左下原文预览；公式/图片可切换框选模式，先查看局部截图。
2. 点击「针对选区提问」，每次写自己的问题后再发送；也可直接在右侧输入。提示词只是可编辑草稿，不自动请求。演示模式仍返回明确标注的固定教案。
3. 「取消选中」或 Esc 会清除文字/截图、高亮和锁定目标，取消正在生成或播放的任务；保留板书历史和阅读书签。弹窗内 Esc 先关闭弹窗，保留问题草稿与选区。
4. 黑板可查看步骤、复制 LaTeX、回到原文、选步骤追问。演示固定样例会显著注明。
5. 「朗读所选」直接使用确认的原文，不用模型改写。复杂公式先核对。暂停同一声音可原位继续；停止或提问后从未完成句句首恢复。
6. 翻页不会替换已锁定的讲解；新选区/新文档取消旧任务。手动点击「继续朗读」才恢复原文。
7. 本书笔记只保存在当前浏览器 localStorage，按文件内容指纹区分；不发送给模型。会话、教案与阅读书签本轮仅内存保存，刷新后清空。

扫描 PDF 可显示并框选，但没有可靠转写不能逐字朗读。复杂双栏和数学抽取需对照原页。M1 使用当前单页渲染、按页提取，不在后台索引全书。

## 检查与生产构建

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
npm.cmd start
```

E2E 使用本机 Microsoft Edge，由测试在独立端口 4320 启动演示服务，可与日常 4317 服务并行；测试不会自动杀其他进程。测试截图在 docs/screenshots；HTML 报告在 playwright-report。

`npm.cmd start` 提供已构建 dist，仍需要项目局部 tsx 和后端源码。前后端同一回环端口。若端口已占用，停止你刚启动的本项目实例或在 .env 指定 APP_PORT。
