- 「使用 ChatGPT 登录」走官方本地应用 OAuth、动态注册和账号模型目录；多账号选择、退出、重新授权、取消与凭证续期已接入。令牌及可选 Key 由 Windows 加密保存，不读取既有 ChatGPT/Codex 登录文件。
- 文字/看图使用账号授权的 Responses；自然朗读保持独立 TTS 配置，不以账号 token 冒充语音 API Key，不自动切换计费方式。默认仍是清楚标注的演示模式。
- 已检查实际 exe 的 PDF 选区/演示黑板/登录设置/720p 布局、首次数据目录创建、单实例、Windows 加密、学习记录恢复与自动重启；关闭窗口后服务确实退出。
- 最终 typecheck、lint、build、桌面打包通过；316 项单元/后端测试、49 项浏览器场景通过。真实登录、账号模型权限、理论答案和真人声音均未测。详见 verification.md 最新节。

## 本轮方向调整（2026-09-29）

用户明确只需打字交互，优先专业教材解答质量与好听的朗读。默认路径改为文字问题→模型教案→听这次讲解；麦克风入口收起，不继续开发 GPT-Live。原 PRD 和已有语音功能不删除，不改变此前真人验收状态。

- 回答直接提供「听这次讲解」「继续这次讲解」「从头听讲解」，复用既有 TeachingPlan 和单一音频控制器；打字停止输出，独立原文书签保留。
- 文字/视觉模型可分别指定 reasoning.effort，空值省略；新增教学 token 上限与独立较长超时。截断回答明确失败、保留已知用量，不自动换模型。设置显示实际参数。
- 默认 TTS 音色 marin；强模型生成保留假设、限制条件与推导逻辑的自然口头稿，TTS 只负责朗读。README/.env.example 提供 Astra+xhigh+自然 TTS 配置建议，尚未验证账号权限。
- 验证结果见 verification.md 最新节；无 .env、未发付费 API 请求，不能宣称真实中文声音或理论正确性已验收。

## 已完成

- 本轮根据“太快、看不出功能”反馈，语速最低统一为 0.25×，增加 0.35 / 0.5 / 0.6 档，并保存本机偏好。朗读中调速从当前未完成句重播；暂停时保持暂停。Realtime 新速度在下一步骤、服务端确认后生效。
- 顶栏「功能体验」直接进入真实 PDF 选段→播放→暂停→同句续读引导；状态由实际播放器事件推进。另有分步板书、麦克风本机演练入口，选区旁直接「读并讲」。明确标注固定教案与未连接 AI，未伪造可用能力。

- 保留 M0/M1/M2：真实 PDF 阅读、文字/截图选区、每次自定义问题、清选区、结构化黑板、TTS、句级书签、逐段陪读、录音草稿、IndexedDB 记录恢复和导出。
- M3 官方 OpenAI Realtime / WebRTC 适配：后端交换会话，不向浏览器暴露长期 Key；实时麦克风状态独立于单一声音输出。
- 文字/语音共用当前授权选区和可见黑板；Realtime 使用同一 TeachingPlan。工具白名单、本地校验、幂等 ID、超时、成功回执后才请求口述当前步骤；每步停顿。
- 本机声音检测优先停音，服务端 VAD 和有效转写确认提问；噪声/无效转写不编造答案。迟到转写、旧 generation、被取消或不完整工具响应不能写板书。
- 打断同步静音，取消生成并等待清除输出回执；超时关闭。生成完成不等于播放完成，未完整播出的转写明确标记；不会标原文已读。
- 原文 TTS 与实时声音共享 AudioCoordinator；原文句书签独立保留。继续原文、继续步骤、定位可见板书及下一步放慢语速的接口已接入。
- 可见的麦克风关闭按钮、手动重连；停止/换目标/隐藏/离线释放设备。十分钟上限、两分钟闲置、后端三十秒失联清理；关闭是否被服务商确认另行记录，不等同计费封顶。
- 无 Key 的真实本机声音检测演练：麦克风仅在本机检测并暂停，不上传、不转写、不假装有 AI。
- 本地语音面板、用量状态、打断标记持久化；实际检查桌面与 720p 页面，展开语音设置时为对话保留滚动空间。
- typecheck / lint / build 通过；316 项单元/模拟接口和 49 项 Edge 场景通过，生产 smoke 无页面错误、无付费调用。精确证据见 [verification.md](verification.md)。

- 真人中文麦克风、直接插话延迟、回声/咳嗽/噪声、公式读法、自然语气、扬声器无叠音仍未测。本机 WebRTC + 合成输入/模拟模型通过不能替代这些验收。

- A12 的连续 20 分钟真人学习仍未测；500 页/复杂双栏/扫描书与长时内存仍待实际样本验收。
- 教学讲解中断恢复到未完成步骤；原文按句恢复，不伪造实时语音逐词播放位置。不保存 PDF blob，刷新后需重选原 PDF。
- 浏览器退出或网络失败时，上游关闭可能未确认，仍可能有费用；本机限时不是供应商硬计费限额。

## 用户最少操作

1. 双击桌面「PDF AI Teacher」图标，无需终端。软件目录要完整保留；开发者仍可使用 npm.cmd run dev 启动网页开发版。
2. 点「使用 ChatGPT 登录」，在官方网页完成授权，回到软件选择账号实际提供的解题模型，再点「应用并重启」。无需把账号密码或 Key 发到聊天。
3. 打开 PDF、选段、打字提问。专业模型权限与答案需首次实际验证；未登录时教案为固定演示。
4. 如需自然 AI 朗读，在设置→「自然朗读与高级 API 设置」仅在本机填写语音 API Key，保存并重启，再由用户确认用一个短句测试。未配置时不假报语音已接通；最低语速 0.25×。
