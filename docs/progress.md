# 进度

## 已完成

- M0/M1：真实 PDF.js、文字/区域选区、可编辑问题、取消选区、上下文锁定、结构化黑板、TTS 适配、暂停/停止/句级续读。原 PRD、AGENTS、START_HERE 未修改。
- M2 课堂：逐句/逐段/只讲所选；只朗读/读并讲/只讲解。原文结束再生成教案，先展示对应板书再播该步 speechText，每步停顿，段末检查题。仅使用用户选区，不自动通读整本书。
- 原文与讲解共用唯一 AudioCoordinator，原文书签独立保留；打断后继续原教学步骤或通过「回原文继续」恢复原文。不同回答相同 stepId 不会串音。
- 真实 getUserMedia / MediaRecorder 输入、独立后端转写、可编辑转写草稿。60 秒/4 MiB，上游取消、重复提交保护、静音/权限拒绝/设备缺失提示；取消、隐藏、离线、卸载释放设备。演示不上传或伪造转写。
- 受限节点/箭头图示，安全校验与 SVG 渲染；板书来源与同一教案一致，支持「讲这一步」。
- IndexedDB 每书记录、同步恢复快照、刷新后重新导入同一 PDF 恢复；保存原文句级书签及教学步骤，恢复时不自动播放。
- JSON/Markdown 导出、严格导入、单本删除与保存暂停；跨书、来源、页号、文本版本校验；配额错误保留内存与导出入口。
- 原文/数学读法校对入口，生成独立内容版本，不改 PDF 或旧教案。
- 模型、转写用量与取消状态诊断；价格未知不显示免费。保留 M3 接口。
- typecheck / lint / build 通过；**140 项单元/接口模拟测试、28 项 Edge 浏览器测试通过**。实际查看 M2 陪读及 720p 截图；生产 smoke 0 pageErrors / 0 providerCalls。

## 未完成 / 待验

- 无真实 Key，未发起付费文字、视觉、TTS、转写请求；模型配置不代表账号权限已验证。
- 浏览器实际 MediaRecorder 管线使用合成音/静音测试通过；真人麦克风、中文数学词转写、扬声器听感和无叠音仍未测。
- 自动化 20 次打断/恢复通过，**不等于真人连续学习 20 分钟验收**；A12 仍未测。
- 教学解释恢复到未完成步骤；同一会话保留的音频队列可从当前句恢复，重启后解释从该步骤开头重播；原文按经版本校验的句书签恢复。
- 不保存 PDF blob，恢复需重新选择原 PDF；没有全书检索、OCR 或大文件后台索引。500 页/复杂双栏/扫描书实际样本验收仍未测。
- M3 连续实时音频、真人直接开口插话、回声、未播内容修剪、实时板书工具回执均未实现。

## 用户最少操作

1. 当前本地服务保持运行；刷新 http://127.0.0.1:4317 并重新打开 PDF。电脑重启后运行 `npm.cmd run dev`。
2. 选中文字 → 展开「课堂陪读」→ 开始陪读 → 文字追问 → 继续陪读。右侧录音入口在演示模式仅体验设备流程。
3. 在本机 .env 配置 Key 与文字/TTS/转写模型，关闭演示并重启，才会有真实 AI 讲解和语音转写。不要在聊天中发送 Key。
4. 用短样本验证中文转写与 TTS，再做 20 分钟多次打断/恢复真人验收；完成后才评估进入 M3。
