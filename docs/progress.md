## 用户最少操作

1. 在本目录运行 `npm.cmd run dev`，打开 http://127.0.0.1:4317 。
2. 点击「先试试自制示例」，选一段 → 朗读 → 文字问 → 查看板书 → 继续；试听本机声音是否清楚。
3. 需要真实 AI 时，在本机复制 .env.example 为 .env，填写自己的 Key 与账号可用模型，DEMO_MODE=false 后重启。不要把 Key 发进聊天。
4. 先做短文字、一个局部公式截图、一个短句的真实验收，并记录结果，再决定进入 M2。

完整命令与测试证据见 README.md 和 verification.md。
